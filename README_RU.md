# Night Music Rider — 0.3.2

Доработанная версия с изменёнными второй и третьей трассами (они больше не похожи на первую) и сплэш-экраном при запуске с пометкой «Made with Unity».

## Изменения 0.3.2

- Вторая трасса переименована в **Neon City Pulse** (118 BPM): другая мелодия, аккорды, форма (городские пульсирующие повороты).
- Третья трасса переименована в **Hyper Storm** (146 BPM): более агрессивный ритм, резкие повороты и высота, другая музыкальная структура.
- Добавлен сплэш-экран при запуске с изображением игры и надписью «Made with Unity».
- Ресурсы Android синхронизированы.
